# Historical coverage manifests

Per-year enumeration manifests produced by `enumerate-history` —
machine-readable record of every CNMV item found in BOE Sección III,
departamento 1040, per day, with the identifier list frozen at
enumeration time.

File layout per period: `boe_history_<start>_<end>.jsonl` — one JSON
line per day: `{date, items[], error?}`.

Coverage matrix (per period): `coverage_matrix.json` — generated by the
build; see `docs/coverage/h0-handoff.md` for the reconciliation and
`docs/coverage/<range>.md` for per-range reports.
